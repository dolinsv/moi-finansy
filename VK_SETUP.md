# Публикация МоиФинансы как VK Mini App

## Шаг 1. Создайте приложение в ВК

1. Откройте [https://dev.vk.com](https://dev.vk.com) и войдите.
2. Нажмите **Создать приложение**.
3. Выберите тип **Mini Apps** (мини-приложение).
4. Укажите название, например: `МоиФинансы`.
5. После создания откройте **Настройки** и скопируйте **ID приложения**  
   (число вида `54033288`).

Пришлите этот ID — подставлю его в `vk-hosting-config.json`.

Ссылка на приложение будет:
- `https://vk.com/appВАШ_ID`
- `https://m.vk.com/appВАШ_ID`

---

## Шаг 2. Подготовьте локальный сервер

В одном терминале:

```bash
npm install
npm run dev
```

Сервер должен быть на **http://127.0.0.1:5175/**

---

## Шаг 3. Поднимите туннель

### Вариант A — VK Tunnel (официальный)

> В документации ВК указано: с 2 октября 2025 VK Tunnel может быть недоступен из‑за техработ.  
> Если не заработает — используйте вариант B.

В **втором** терминале:

```bash
npm run tunnel
```

Следуйте подсказкам в консоли (логин ВК / подтверждение).  
В конце появится HTTPS-ссылка вида:

`https://user-xxxx.tunnel.vk-apps.com`

### Вариант B — Cloudflare Tunnel (если VK Tunnel недоступен)

```bash
npx cloudflared tunnel --url http://127.0.0.1:5175
```

Скопируйте выданную HTTPS-ссылку (`https://….trycloudflare.com`).

---

## Шаг 4. Укажите URL в настройках Mini App

1. В кабинете приложения откройте **Настройки**.
2. Раздел **Размещение** / **Версия для разработки**.
3. Включите **режим разработки**.
4. В поле **URL для разработки** вставьте HTTPS-ссылку из туннеля  
   (без слэша на конце или как просит форма).
5. Сохраните.

Также можно указать этот URL для:
- мобильной версии
- m.vk.com
- десктопной версии vk.com

---

## Шаг 5. Откройте приложение в ВК

Перейдите по ссылке:

`https://vk.com/appВАШ_ID`

или

`https://m.vk.com/appВАШ_ID`

Должно произойти:
1. Загрузка МоиФинансы
2. Автоматический вход через ваш аккаунт ВК
3. Без формы логина/пароля

---

## Шаг 6. Боевой деплой (позже)

Когда всё проверите локально:

1. Впишите `app_id` в `vk-hosting-config.json`
2. Выполните:

```bash
npm run build
npm run deploy:vk
```

Либо задеплойте `dist` на Vercel/Netlify и укажите постоянный HTTPS URL в настройках приложения (уже не режим разработки).

---

## Частые проблемы

| Проблема | Что сделать |
|---|---|
| Открывается форма логина | Вы не внутри ВК / нет `vk_user_id` в URL. Открывайте через `vk.com/app…` |
| Белый экран | Проверьте, что `npm run dev` запущен и URL туннеля совпадает |
| Tunnel не стартует | Используйте Cloudflare Tunnel (вариант B) |
| Старый кэш | Обновите страницу ВК с полной перезагрузкой |
